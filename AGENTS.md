# Agent guide

Read to understand the repository: `README.md`, `todo.md`, `docs/physics.md`,
the code under `src/w7x_twin/`, `tests/`, `tools/`, `run.sh` and
`pyproject.toml`.

For the numbers, read `results/DIGEST.md`. It carries every scalar of every
record verbatim and each array as its length, range, median and end points,
which is 159 kB against the 1 MB the records themselves come to. It is
generated by `python tools/digest_results.py` and stamps the sha256 of each
record it read, so a stale entry is detectable; regenerate it whenever a record
is rewritten. Open a record itself only for the array elements the digest
summarises, and for the 1800-run growth-rate grid, whose per-row values the
digest reduces to a column census.

Do not read the following wholesale; they are data, not explanation.

- `results/**/*.json`: computed records, digested above. Open a single record
  only when a task needs elements the digest does not carry.
  `results/magnetics/w7x_field.json` is a 20 MB interpolation table and
  `results/magnetics/w7x_geometry.json` a 1.4 MB geometry export; never open
  either.
- `src/w7x_twin/records/*.json`: digitised measurement inputs. Read only the
  values a task needs.
- `artifact/w7x_twin3d.html`: 22 MB generated page; never open it. The source
  is `artifact/twin3d.template.html`; read it only when changing the viewer.
- `docs/*.png`, `docs/*.jpg`: rendered figures.
